# قرارات التنفيذ — Ashen Gauntlet

## 2026-11-01

- اخترنا Godot 4.7 مع قالب Horizontal Platformer لأن المطلوب لعبة منصات 2D وموبايل landscape، مع الحفاظ على الأنظمة الناضجة الموجودة في القالب.
- اسم المنتج القابل للعرض هو **Ashen Gauntlet**، مع الاحتفاظ بـ `anis 2` كهوية/مرجع prototype داخل التوثيق.
- الأولوية الحالية هي Vertical Slice قابلة للعب: الحركة، القفز المتغير، coyote/jump buffer، فخاخ/أعداء قابلة للقراءة، عملات، checkpoint، هدف نهائي، موت وإعادة سريعة، pause، touch، حفظ محلي.
- لم نستخدم أصولًا خارجية أو كتالوجًا في هذه المرحلة؛ الرسوم الرئيسية procedural داخل Godot لتجنب خلط هوية القطة الموروثة مع هوية Anis، بينما أصول prototype محفوظة غير معدلة تحت `legacy/` و`assets/legacy/`.
- الواجهة الأساسية عربية RTL، لكن محاور اللعب وأماكن أزرار التحكم لا تُعكس. الإنجليزية تبقى جاهزة كبنية لاحقة عبر localization.
- بقيت بنية بيانات المراحل والـautoloads والاختبارات الموجودة، مع إعادة توجيه الرسوم/النصوص بدل إزالة الحماية والـguards التي يعتمد عليها التصدير.
- نطاق 250 مستوى و10 عوالم، الداش، wall-jump، المتجر والتحديات الكاملة هي roadmap؛ النسخة المحفوظة الحالية partial vertical slice وليست ادعاء اكتمال الحملة.
